# RouterOS 实战配置教程

写 **短、直说步骤、照着就能配完** 的课文。不是参数百科。

## 一课 = 一个场景（硬性）

读者带着一个具体问题来，例如「人在外面，用手机 IKEv2 连回家里 RouterOS」。  
**只看这一份课文，必须能把这件事从头做到能测通。** 不许让他再去翻「证书课」「服务器课」「手机课」。

判定：用户做完后，那个问题已经解决。差客户端、差防火墙、差测试，都算没写完。

**同一场景必须写在同一文件。** 步数按场景需要（常 6～15 步），不要为了「短」或「3～8 步」把场景拆开。

| 场景（用户要解决的事） | 这一课必须写到 | 禁止拆成 |
| --- | --- | --- |
| 手机 IKEv2 回家 | CA/服务器/客户端证书、池、Mode Config、Peer、防火墙、导出、手机导入与 IKEv2 配置、Windows 导入与配置、测试 | 只开 Certificates；只配 IPsec；只看 Active Peers |
| WireGuard 回家 | 接口、地址、手机 Peer、防火墙/NAT、手机 App、电脑客户端、握手测试 | 路由器一篇、手机一篇、电脑一篇 |
| PPPoE 家里上网 | 拨号 + masquerade + 电脑能打开网页 | 只建 pppoe、NAT 另开一课 |
| 家里电脑自动拿地址 | DHCP 池/网络 + DNS 转发 | DHCP、DNS 各一课 |
| 家里防火墙 | input + forward + 关掉危险服务，LAN 仍能管路由器 | 概念、Input、Forward、Address List、放行、封禁、看日志 各一课 |
| 第一次连上路由器 | WinBox/MAC 登录、看信息、改名 R1、改管理员密码 | 连接、看信息、改名、改密 各一课 |
| 端口映射给家里服务 | dst-nat + hairpin，外网和家里都能访问 | 只写 dst-nat、回流另开一课 |
| 安全加固 | 改密、关服务、限制管理来源、NTP、立刻备份 | NTP、WinBox、SSH、远程 各一课 |
| 网络不通 | 口 → 地址 → 路由 → DNS → 防火墙，用到 ping/Torch/日志 | Ping、Traceroute、Torch、抓包、连接、CPU、日志 各一课 |

允许分成两课的，只有**真的是两件不同的事**：例如 WireGuard 回家 vs 两地站点；家里 Wi-Fi vs 访客 Wi-Fi；Simple Queue 限一台 vs Queue Tree 限网段。

**刷新目录时：** 章 `00-目录.md`、`docs/实战课表.md`、`COURSE-TREE.md` 只列完整场景课。半成品课从目录拿掉并删除对应文件夹，不要留「另见 xx 课」。

客户端（手机/Windows）步骤写在同一课里。路由器侧每步真机 WinBox；客户端写系统设置路径，有真机就截手机/电脑，没有也把字段写全，**不要因此另拆课文**。

默认：**RouterOS 7.x** + **WinBox 3**（界面英文，说明中文）。  
结构固定：**WinBox 截图 → 操作 → 本步命令 → 验证**。依据：[WinBox](https://help.mikrotik.com/docs/spaces/ROS/pages/328129/WinBox)。

## 实验机（只给 Agent 连，禁止写入教程）

连接信息只读本机 **`lab-env.local.md`**（与本技能同目录，已 gitignore）。没有该文件则先按 `lab-env.example.md` 复制再填。

- **只连 PVE 上的 x86 虚拟机 VMID 901**（RouterOS x86，`lab-env.local.md` 里的 MAC / 管理 IP）
- **严禁连接监听 5009 端口的任何 RouterOS**（那是别的机，不是本课实验机）。WinBox / SSH / API 地址栏禁止写成 `x.x.x.x:5009` 或端口 5009
- WinBox 连 901：无管理 IP 时 **Neighbors → 点 MAC**；有 IP 后用该 IP、**WinBox 默认端口 8291**（不要改成 5009）
- SSH 只打 901 的 22（或 lab-env 写明的 901 管理口），不要打 5009
- 本机可用 WinBox 3 或 WinBox 4；课文写 WinBox，**全部操作图必须是这台 x86 真机窗口**，禁止 AI 假界面、禁止拿别的 ROS 截图顶替
- 教程里登录账号写 `admin`；**真实密码、真实管理 IP、个人昵称一律不准出现在 md / 图 / .rsc**
- 教程密码位只写 `********`，并写「填你自己的管理员密码」
- 登录类截图：密码框必须是空的或圆点，不得露出明文

终端：用 SSH/`New Terminal` 对 **901（x86）** 执行本步命令，核对与 WinBox 一致。连错机先断开。

## 硬性要求

1. 菜单/参数先查 [help.mikrotik.com](https://help.mikrotik.com/docs/spaces/ROS/overview)，禁止瞎编。
2. **每一步**：一张 **真机 WinBox 截图** + 点击/填写 + **这一步的 CLI**。不许「如图」不写路径。
3. WinBox 与 CLI 同一结果。
4. 课文短：不要长文讲原理。路径/地址会变的课，用 **示意图** 讲清（谁连谁、地址怎么变）。读者章节标题必须写成 **`## 网络拓扑及原理图`**（禁止「先看懂」）。图按下方「网络拓扑及原理图」走 `network-v1-diagram` / `packet-flow-diagram`。不要百科、不要 Packet Flow 长文。
5. 文首只保留：`适用版本：RouterOS 7.x`。**不要写**「管理工具：WinBox」，**不要写**「官方依据：…」。官方页面只给 Agent 查菜单，不出现在读者课文里。
6. 脱敏靠**实验机数据**（Identity=`R1`、教程网段、MAC 占位），不要在图上贴白块打码。MAC `00:11:22:33:44:55`；公网 TEST-NET。课程仓可用右上角一处文字水印 `RouterOS 入门实战`，不得用白矩形遮内容。
7. **读者只看到「人写的步骤」。** 写作方法、目录怎么排、模板叫什么，一律不要写进课文、章 `00-目录.md`、课表、仓库首页。像人说话：短句、直说点哪、填什么。不要说明书腔、不要总结腔。

## 课文结构（短）

课文 **H1 题目**必须是新手课名，不要写功能名：

```markdown
# 第 13 课：让 RouterOS 通过 DHCP 接入互联网
```

规则：

- 格式：`第 N 课：` + **一句人话**（做完能得到什么）。优先「让……」；排错课用「查清……」。冒号必须是全角 `：`。
- 全课程从第 1 课连续编号，编号以 `reference.md` 课表为准，**不是**文件夹号（`03-DHCP获取公网IP` 仍可叫第 13 课）。
- 禁止：`# DHCP 上网`、`# Bridge`、`# IKEv2 回家` 这种功能名当题目。
- 目录、课表、`COURSE-TREE.md`、章 `00-目录.md` 的链接文字必须和课文 H1 一致。
- **课文 md 文件名必须等于 H1（去掉行首 `# `）再加 `.md`。** 例：H1 为 `第 13 课：让 RouterOS 通过 DHCP 接入互联网`，文件就是 `第 13 课：让 RouterOS 通过 DHCP 接入互联网.md`。
- Windows 文件名不能含半角 `:` `/` `\` `*` `?` `"` `<` `>` `|`。题目里的冒号只用全角 `：`；斜杠只用全角 `／`（例：`第 38 课：让电脑用 L2TP／IPsec 连回家.md`）。
- 索引文件名不变：`00-目录.md`、`实战课表.md`、`_template.md`。Lab 正文仍与文件夹同号（如 `labs/.../00-环境准备.md`），不要改成课名。
- 文件夹名可以保留旧编号，不要为改标题去改路径。改完文件名后，必须同步课表、章目录、`COURSE-TREE.md`、仓库根 `README.md` 里的链接。

## 常见问题（可省略）

只写**具体、用户容易忽略**的坑，例如：证书 CN 必须等于客户端填的地址；LAN 访问公网映射必须加 hairpin；option 121 客户端不请求则不发。  
不要写「接口名填错」「没点 Apply」这类空话。没有这种坑就**整节不写**。

## 网络拓扑及原理图（画法）

课文里这一节的标题固定为 **`## 网络拓扑及原理图`**，不要用「先看懂」「示意图」「原理」等别名。

读者是新手。凡是「电脑怎么上网、包怎么改地址、隧道怎么回家、VLAN 怎么隔离」，必须在 WinBox 步骤**之前**给图。

**要配图的课（部分，不是每一课）：** VPN、NAT（含端口映射/回流）、防火墙转发路径、端口敲门、DHCP/Option 分流、IPv6、VLAN、双 WAN、策略路由。  
**可省略：** 只改名称/密码、看 CPU/日志、备份导出、纯菜单认识且路径已在上一课讲过。

画图前必须先读并按原文执行这两个技能（本技能不另写一套画法）：

| 图 | 技能 | 何时 |
|----|------|------|
| **A · 整体原理 / 网络拓扑** | `network-v1-diagram` 的 A 类 | 谁连谁、左外网 / 中 R1 / 右内网（或 VPN） |
| **B · 数据包变形** | `packet-flow-diagram`（与 `network-v1-diagram` 的 B 类同一套） | 地址或端口会 Before → After：NAT、端口映射/回流、防火墙改写、VPN 出站伪装 |

未说明时：NAT/端口转发/回流/VPN 回家 **A + B 各一张**；只讲谁连谁、包头不变（如纯 VLAN 口类型）可以只要 A。

课程仓落盘（不要写到技能仓库的 `docs/images/`）：

- A：本课 `images/00-原理.drawio` + `images/00-原理.png`。按 `network-v1-diagram`：draw.io 手绘线框（暖纸色 `#fffaf3`、`sketch=1`、楷体、`mxgraph.networks` 图标）。禁止 `GenerateImage`、深蓝霓虹、3D 路由器、图内大标题。
- B：本课 `images/00-包变形.png`（按 packet-flow-diagram：Mermaid `flowchart LR`、白底、①～⑤、分区 emoji；用该技能的 `scripts/render.py` 或 `network-v1-diagram` 的 `render_packet_flow.py` 出 4800px PNG）

课文里仍用本课图注：`<p align="center">图(1) …</p>`，从 1 起编。有 A+B 时图(1)=原理、图(2)=包变形，WinBox 从下一号接着。  
**不要**把技能里的画法说明、「复制此图」写进读者课文。

图必须同时做到：

1. **标明步骤**：①②③… 能对上包走的顺序（或课文步骤）。
2. **讲清原理**：谁是外网、谁是 R1、谁是家里电脑/手机；变了的地址/端口画出 Before → After。
3. **一看就懂**：图下用一句话人话。不要堆英文缩写墙。

禁止：用 WinBox 截图冒充拓扑；用 AI 画假 WinBox；用 `GenerateImage` 或文生图画原理图（深蓝底、霓虹、3D 图标、图里出现 `LEFT`/`CENTER`/`RIGHT` 都算）；用 Mermaid 顶替 A 类整体原理图；用 GenerateImage 画 B 类流程图；图里出现真实公网/密码/昵称（用 `192.168.88.0/24`、`203.0.113.10`）。重画旧课的 `00-原理.png` / `00-原理.svg` 时改成 draw.io 手绘拓扑，源文件留下 `00-原理.drawio`。本机没有 draw.io 就停，不要退回文生图。

### 红框（位置必须对）

- 只标本步要操作的东西：① 左侧/顶栏**这一步的菜单名** ② 要填的**输入框/勾选** ③ 关键结果（表格里那一行）。每张图 1～3 处。
- **框边紧贴目标文字或控件**，套住完整菜单名或整行邻居。不要漂在 logo、锁图标、空白表格、窗口装饰上。
- 框里的字必须是 WinBox 里本来就有的。本步窗口没有的名字禁止画上去。
- **反例（禁止）**：Neighbors 登录窗上在锁图标处标 `Firewall`、在邻居列表空白处标 `Connections`——这两个菜单这步根本没有，位置也是错的。
- 标签用中文，写在框**外侧**空白，不要盖住菜单字。用描边红框，不要红底白字小牌贴到无关位置。

### 禁止白色方框 / 白底浮层

- **不要**在 Connect / Login / Password 上再盖一层白色矩形。WinBox 自己的输入框就要露出来：Connect 填 MAC 或 IP，Login 填 `admin`，Password 是圆点。
- 禁止用白色块打码、高亮、遮挡被切断的 `Connect`/`Login`/`Password` 标签。
- 图里若仍有真实隐私：先改实验机再截（R1、`192.168.88.0/24`、密码框圆点），不要贴白矩形。

### 图注与文件

- **图注不属于图片。** 不要在 PNG/SVG 里画底栏、不要把「图(1) …」烧进像素。截完图后，在 Markdown **紧挨图片的下一行**居中写正文，例如：`<p align="center">图(1) ikev2防火墙设置</p>`。这是课文里的一行字（随主题黑/深色），不是 WinBox 底栏那种深色条。
- **图号从 1 开始，禁止图(0)。** 原理图文件名可以是 `images/00-原理.png`，包变形 `images/00-包变形.png`，图注仍是 `图(1) …`；WinBox 图接着编。序号与文件名无关。
- 课程仓可用右上角一处文字水印 `RouterOS 入门实战`，不得用白矩形遮内容。
- 文件名：`images/01-打开DHCP.png`（basename 两位序号 + 短中文）。
