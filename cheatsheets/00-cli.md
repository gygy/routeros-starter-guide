# CLI 常用命令

RouterOS 7。详细步骤见 [实战课表](../docs/实战课表.md)。

| 做什么 | 命令 |
| --- | --- |
| 资源 | `/system/resource/print` |
| 身份 | `/system/identity/set name=R1` |
| 接口 | `/interface/print` |
| 地址 | `/ip/address/print` |
| 路由 | `/ip/route/print` |
| DHCP 租约 | `/ip/dhcp-server/lease/print` |
| NAT | `/ip/firewall/nat/print` |
| 防火墙 | `/ip/firewall/filter/print` |
| 备份 | `/system/backup/save name=r1` |
| 导出 | `/export compact` |
| Ping | `/ping 1.1.1.1 count=5` |
