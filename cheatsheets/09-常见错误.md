# 常见错误

按现象找课文：[故障速查](../cookbook/00-home/故障速查.md)。

| 现象 | 先查 |
| --- | --- |
| Neighbors 没有设备 | 同一二层、本机有 IPv4、防火墙 |
| IP 为 0.0.0.0 连不上 | 点 MAC，不要点 IP |
| 能 ping 网关不能上网 | 默认路由、NAT 出接口 |
| 能 ping IP 不能打开网页 | DNS |
| PPPoE 通了 LAN 不通 | masquerade 出接口要用 `pppoe-out1` |
| 改防火墙后 WinBox 掉线 | Safe Mode；用 MAC 再连 |
