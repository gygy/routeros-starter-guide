# 故障速查

遇到问题先看现象，再打开对应课文。不要从功能名翻手册。

固定顺序（上网不通时按这个走）：

> 线有没有插好 → 有没有 IP → ARP 能不能认上 → ping 网关 → ping 外网 IP → DNS → 路由 → NAT → 防火墙 → MTU

完整跟做：[第 44 章：查清网络为什么不通（按流程）](<../../docs/14-故障排查(troubleshooting)/01-网络故障排查流程/第 44 章：查清网络为什么不通（按流程）.md>)
