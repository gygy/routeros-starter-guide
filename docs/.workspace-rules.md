# 研发目录规范

> 版本：V1.1
> 本文件是目录结构、归档位置、命名和旧目录别名的**唯一来源**。
> 修改目录或命名时只改本文件。不要把目录树或命名词表抄回 `AGENTS.md` 或任何技能。

`AGENTS.md` 只规定必须遵守的约束。`ai-workspace-governance` 只规定如何检查、归类和迁移。

## 3. 目录管理

### 3.1 禁止新的一级目录

`docs/` 下只允许：

```text
01-规划
02-输入
03-分析
04-方案
05-需求
06-执行
07-验证
08-交付
09-知识
```

现有目录能承载的内容，不得另建一级目录。

### 3.2 禁止平行重复目录

不得再出现与标准目录重复或高度相似的目录，例如：

```text
docs/需求/
docs/需求分析/
docs/PRD/
docs/产品需求/
```

### 3.3 保持目录稳定

目录一旦按本文件建立，后续用移动、归档和更新文件解决问题，不改目录结构。要改结构，只改本文件，并同步检查归档表和旧目录别名。

## 4. 研发对象命名体系

目录管**阶段**，文件名管**对象 + 成果类型 + 版本**。Skill / Agent 是生产方法与角色，**不得**进入文件名。

分层：

```text
Skill = 生产方法
Agent = 生产角色
文件 = 研发成果
目录 = 成果分类（九段）
```

### 4.1 三类命名族

先判断材料性质，再套模板。段与段之间用英文短横线 `-`。

#### A. 正式成果（分析 / 方案 / 需求 / 验证交付基线 / 知识等）

```text
[对象]-[成果类型]-Vx.y.扩展名
```

能识别产品时，**必须**加产品短名首段：

```text
[产品短名]-[对象]-[成果类型]-Vx.y.扩展名
```

示例：

```text
空料盘上线-业务需求-V1.0.md
空料盘上线-产品需求说明书-V1.0.md
空料盘上线-业务流程-V1.0.svg
LDCS-PDA增加工作台-产品需求说明书-V1.0.md
LDCS-成型工序派工与调度流程-流程设计-V1.0.md
```

| 要素 | 含义 |
| --- | --- |
| 产品短名 | 能识别则必写：`LDCS`、`WCS`、`iWES` 等；与目录 `{产品}/` 一致 |
| 对象 | 主题/模块/能力；全链路同名；勿再重复产品短名 |
| 成果类型 | §4.3 词表；与归档关键词同族 |
| 版本 | 文档版 `V1.0` / `V1.1` / `V2.0`（升版改号，禁止 `最终版`/`xxx-v2`） |

#### B. 原始输入（02-输入，不过度加工）

```text
[资料类型]-[来源或对象]-YYYYMMDD.扩展名
```

资料类型在前（与二级目录用途对应），日期表示**何时收到**。

示例：

```text
客户需求-空料盘上线-20260921.md
现场资料-3号厂房-20260921.md
原始需求-自动派工-20260921.md
业务资料-成型工序-20260921.md
历史资料-一期验收-20260501.md
```

不要用 `Vx.y`：避免把「收到的材料」误当成已确认基线。

#### C. 过程记录（跟踪、评审、执行日志等）

```text
[对象]-[记录类型]-YYYYMMDD.扩展名
```

示例：

```text
空料盘上线-评审记录-20260921.md
空料盘上线-测试记录-20260921.xlsx
空料盘上线-研发周报-20260921.md
```

能识别产品时同样可加首段：`LDCS-空料盘上线-评审记录-20260921.md`。

#### 软件版本资料（发布说明等）

产品版本与文档版本分开：

```text
[产品]-V{产品版}-[成果类型]-Vx.y.扩展名
```

例：`WCS-V1.2-发布说明-V1.0.md`。

#### 共通禁止

- Skill / Agent 名进文件名
- `最终版`、`最新`、`new`、`final`、`临时版`
- 旧式 `LDCS 主题-产品需求.md`（空格连接，或文种只用短词「产品需求」）

产品短名识别来源（任一即可）：路径含产品子目录、文件名已有产品前缀、用户指定、仓库默认产品（如本仓 LDCS）。

**暂不强制对象 ID**（如 `REQ-2026-001`）。

### 4.2 怎么选族

| 材料性质 | 族 | 标识 | 模板 |
| --- | --- | --- | --- |
| 正式研发成果 | A | 文档版本 `Vx.y` | `[产品-][对象]-[成果类型]-Vx.y.ext` |
| 原始输入（02-输入） | B | 日期 | `[资料类型]-[来源或对象]-YYYYMMDD.ext` |
| 过程记录 | C | 日期 | `[产品-][对象]-[记录类型]-YYYYMMDD.ext` |
| 软件版本资料 | A 变体 | 产品版 + 文档版 | `[产品]-V{产品版}-[成果类型]-Vx.y.ext` |
| 历史资料 | B | 日期 | 同原始输入 |

原则：输入/过程用日期；正式成果用版本；能识别产品则正式成果（及可选过程记录）带产品短名。
