# 课程目录规范

> 本仓库是 **RouterOS 教程**，不是需求分析/PRD 项目。  
> **禁止**再建九段研发目录（`01-规划 Planning`、`05-需求 Requirement` 等）。

`docs/` **只放课程课文**。章目录命名：`编号-中文(英文)`。  
编号按**家庭/个人用户使用频率**排：越常用越靠前（入门、DHCP、NAT、防火墙、无线、VPN），交换/动态路由/MPLS 靠后。

---

## 1. 标准目录（课程）

```text
docs/
├─ 00-入门(introduction)/
├─ 01-网络基础(networking-basics)/
├─ 02-RouterOS基础(routeros-basics)/
├─ 03-DHCP与DNS(dhcp-dns)/
├─ 04-NAT(nat)/
├─ 05-防火墙(firewall)/
├─ 06-无线(wireless)/
├─ 07-VPN(vpn)/
├─ 08-QoS(qos)/
├─ 09-高可用(high-availability)/
├─ 10-二层交换(switching)/
├─ 11-三层路由(routing)/
├─ 12-监控(monitoring)/
├─ 13-安全(security)/
├─ 14-故障排查(troubleshooting)/
├─ 15-性能优化(performance)/
├─ 16-自动化(automation)/
├─ 17-生产环境(production)/
├─ 18-动态路由(dynamic-routing)/
├─ 19-MPLS(mpls)/
└─ 20-高级(advanced)/
```

课文模板：`docs/_template.md`（实战七段：目的 → 网络 → WinBox 逐步截图 → 对应命令 → 检查/测试 → 排错）。动手内容放 `labs/`，完整配置放 `configs/`，功能脚本放 `scripts/`。  
Markdown 链接里目录名含括号时，写成 `[标题](<docs/00-入门(introduction)/xxx.md>)`。

一课一个目录，截图不堆总盘：

```text
docs/03-DHCP与DNS(dhcp-dns)/04-DHCP服务器/
  ├─ 04-DHCP服务器.md
  └─ images/01-打开DHCP.png
```

禁止在仓库根再建 `RouterOS教程/` 平行树。写作大纲（01-基础、03-互联网…）到现有章的映射见技能 `ros-beginner-tutorial/reference.md`。

## 8. 隐私与脱敏（强制）
