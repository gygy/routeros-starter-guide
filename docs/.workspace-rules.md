# 课程目录规范

> 本仓库是 **RouterOS 教程**，不是需求分析/PRD 项目。  
> **禁止**再建九段研发目录（`01-规划 Planning`、`05-需求 Requirement` 等）。

`docs/` **只放课程课文**。章目录命名：`编号-中文(英文)`。

---

## 1. 标准目录（课程）

```text
docs/
├─ 00-入门(introduction)/
├─ 01-网络基础(networking-basics)/
├─ 02-RouterOS基础(routeros-basics)/
├─ 03-二层交换(switching)/
├─ 04-三层路由(routing)/
├─ 05-防火墙(firewall)/
├─ 06-NAT(nat)/
├─ 07-DHCP与DNS(dhcp-dns)/
├─ 08-无线(wireless)/
├─ 09-VPN(vpn)/
├─ 10-动态路由(dynamic-routing)/
├─ 11-QoS(qos)/
├─ 12-高可用(high-availability)/
├─ 13-MPLS(mpls)/
├─ 14-自动化(automation)/
├─ 15-监控(monitoring)/
├─ 16-安全(security)/
├─ 17-故障排查(troubleshooting)/
├─ 18-性能优化(performance)/
├─ 19-生产环境(production)/
└─ 20-高级(advanced)/
```

课文模板：`docs/_template.md`。动手内容放 `labs/`，完整配置放 `configs/`，功能脚本放 `scripts/`。  
Markdown 链接里目录名含括号时，写成 `[标题](<docs/00-入门(introduction)/xxx.md>)`。

## 8. 隐私与脱敏（强制）

教程、配置、脚本、图片、截图、拓扑图**严禁**个人真实信息。

| 类型 | 处理 |
| --- | --- |
| 账户、密码、密钥 | `admin` / `ISP_USER` / `ISP_PASS` / `********` |
| MAC | `00:11:22:33:44:55` |
| 公网 IP | `192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24` |
| 个人昵称 | 禁止（含 lei、sheng 等） |
