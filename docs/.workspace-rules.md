# 课程目录规范

> 本仓库是 **RouterOS 教程**，不是需求分析/PRD 项目。  
> **禁止**再建九段研发目录（`01-规划 Planning`、`05-需求 Requirement` 等）。

`docs/` **只放课程课文**（`00-introduction` … `20-advanced`）。

---

## 1. 标准目录（课程）

```text
docs/
├─ 00-introduction/
├─ 01-networking-basics/
├─ 02-routeros-basics/
├─ 03-switching/
├─ 04-routing/
├─ 05-firewall/
├─ 06-nat/
├─ 07-dhcp-dns/
├─ 08-wireless/
├─ 09-vpn/
├─ 10-dynamic-routing/
├─ 11-qos/
├─ 12-high-availability/
├─ 13-mpls/
├─ 14-automation/
├─ 15-monitoring/
├─ 16-security/
├─ 17-troubleshooting/
├─ 18-performance/
├─ 19-production/
└─ 20-advanced/
```

课文模板：`docs/_template.md`。动手内容放 `labs/`，完整配置放 `configs/`，功能脚本放 `scripts/`。

## 8. 隐私与脱敏（强制）

教程、配置、脚本、图片、截图、拓扑图**严禁**个人真实信息。

| 类型 | 处理 |
| --- | --- |
| 账户、密码、密钥 | `admin` / `ISP_USER` / `ISP_PASS` / `********` |
| MAC | `00:11:22:33:44:55` |
| 公网 IP | `192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24` |
| 个人昵称 | 禁止（含 lei、sheng 等） |

截图每张一处水印 `RouterOS 入门与精通`，内容区右上角。工具：`automation/protect-media.ps1`。
