# 查看路由器信息

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[First Time Configuration](https://help.mikrotik.com/docs/spaces/ROS/pages/328151/First+Time+Configuration)

## 目的

看版本、CPU、接口是否起来。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：打开资源

WinBox：`System → Resources`

看 version、CPU、memory。

![第1步](images/01-资源.png)

```routeros
/system/resource/print
```

## 第2步：看接口

WinBox：`Interfaces`

Running 的口才是有链路的。

![第2步](images/02-接口.png)

```routeros
/interface/print
```

## 检查

WinBox：`System → Resources`

```routeros
/system/resource/print
```

## 常见问题

MAC 连接不稳定时，先做「连接路由器」课。
