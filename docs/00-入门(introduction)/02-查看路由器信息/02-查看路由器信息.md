# 查看路由器信息

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[System Resource](https://help.mikrotik.com/docs/spaces/ROS/pages/328084/System+Resource)

## 目的

先看版本、CPU、内存和接口是否正常。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：看资源

WinBox：`System → Resources`

动作：打开后看 Uptime、CPU、Memory、Free HDD。

![第1步](images/01-资源.png)

```routeros
/system/resource/print
```

## 第2步：看接口

WinBox：`Interfaces`

动作：确认 ether / pppoe / bridge 的 R（Running）标志。

![第2步](images/02-接口.png)

```routeros
/interface/print
```

## 检查

WinBox：System → Resources；Interfaces

```routeros
/system/resource/print
/interface/print
```

## 常见问题

CPU 长期偏高先查 Torch 和防火墙。
