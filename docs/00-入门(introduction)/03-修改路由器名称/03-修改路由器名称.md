# 修改路由器名称

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Identity](https://help.mikrotik.com/docs/spaces/ROS/pages/40959670/Identity)

## 目的

改成 R1，终端提示符更好认。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：设置 Identity

WinBox：`System → Identity`

动作：Name 填 R1，OK。901 已实配为 R1。

![第1步](images/01-Identity.png)

```routeros
/system/identity/set name=R1
```

## 检查

WinBox：终端提示符变为 [admin@R1]

```routeros
/system/identity/print
```

## 常见问题

不要用个人昵称当名称。
