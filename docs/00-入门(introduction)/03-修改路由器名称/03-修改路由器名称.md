# 修改路由器名称

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Identity](https://help.mikrotik.com/docs/spaces/ROS/pages/40959670/Identity)

## 目的

改 identity，WinBox 标题更好认。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：打开 Identity

WinBox：`System → Identity`

Name 填 `R1`，OK。

![第1步](images/01-Identity.png)

```routeros
/system/identity/set name=R1
```

## 检查

WinBox：`System → Identity`

```routeros
/system/identity/print
```

## 常见问题

名字不要用个人昵称。
