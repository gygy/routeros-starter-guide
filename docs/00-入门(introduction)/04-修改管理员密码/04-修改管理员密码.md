# 修改管理员密码

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[User](https://help.mikrotik.com/docs/spaces/ROS/pages/328166/User)

## 目的

改掉默认空密码或弱密码。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：改密码

WinBox：`System → Password`

动作：Old / New / Confirm 填你自己的密码（截图保持空白），点 Change。教程只写 ********。

![第1步](images/01-用户.png)

```routeros
/user/set [find name=admin] password="********"
```

## 检查

WinBox：能用新密码重新登录 WinBox

```routeros
/user/print
```

## 常见问题

改完立刻用新密码重连一次。
