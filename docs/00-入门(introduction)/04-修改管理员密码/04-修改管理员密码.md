# 修改管理员密码

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[User](https://help.mikrotik.com/docs/spaces/ROS/pages/328146/User)

## 目的

给 admin 换成你自己的强密码。教程不写真实密码。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：打开用户

WinBox：`System → Users`

双击 `admin`，Password 填你的新密码，OK。

![第1步](images/01-用户.png)

```routeros
/user/set [find name=admin] password=********
```

## 检查

WinBox：`System → Users`

```routeros
/user/print
```

## 常见问题

改完用新密码重新开 WinBox。不要把密码写进配置文件再上传。
