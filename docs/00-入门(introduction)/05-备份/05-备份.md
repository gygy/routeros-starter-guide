# 备份

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Backup](https://help.mikrotik.com/docs/spaces/ROS/pages/328182/Backup)

## 目的

改配置前先留一份可恢复文件。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：保存备份

WinBox：`Files → Backup`

动作：Name 填 lab-demo，Create Backup。901 已执行。

![第1步](images/01-备份.png)

```routeros
/system/backup/save name=lab-demo
```

## 第2步：导出文本

WinBox：`New Terminal`

动作：执行 export，把文本另存到电脑。

![第2步](images/02-导出.png)

```routeros
/export file=demo-backup
```

## 检查

WinBox：Files 里有 .backup

```routeros
/file/print where name~"lab-demo"
```

## 常见问题

binary 备份含密码；外发只用脱敏 export。
