# 第 3 课：让改配置之前先留一份备份

> 适用版本：RouterOS 7.x

## 目的

改配置前先备份。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：做 Backup

WinBox：`Files / System Backup`

动作：生成 .backup（含敏感信息，妥善保存）。

![图(1) 做Backup](images/01-备份.png)

<p align="center">图(1) 做Backup</p>


```routeros
/system/backup/save name=lab-backup
```

## 第2步：Export

WinBox：`New Terminal`

动作：export 出可读配置。

![图(2) Export](images/02-导出.png)

<p align="center">图(2) Export</p>


```routeros
/export file=lab-export
```

## 检查

WinBox：Files 里有备份文件

```routeros
/file/print where name~"lab"
```
