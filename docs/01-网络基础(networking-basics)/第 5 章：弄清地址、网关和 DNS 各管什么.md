# 第 5 章：弄清地址、网关和 DNS 各管什么

> 先把地址、网关、DNS 这三件事记住。VLAN、OSI 以后用到再看。

## 你只要记住这三件事

1. **地址 + 掩码**：例如 LAN `192.168.88.1/24`，表示这台路由在 `192.168.88.0/24` 里。  
2. **网关**：电脑的「下一跳」。家里电脑网关填路由器 LAN 地址（官方默认思路是 `192.168.88.1`）。  
3. **DNS**：把域名变成 IP。电脑可以填路由器，路由器再转发到运营商或公共 DNS。

## 怎么判断「断在哪」

| 现象 | 多半是 |
| --- | --- |
| ping 不通 `192.168.88.1` | 线、口、网段、网桥 |
| 能 ping 网关，ping 不通 `8.8.8.8` | WAN、默认路由、NAT、运营商 |
| 能 ping IP，浏览器打不开网站 | DNS |
