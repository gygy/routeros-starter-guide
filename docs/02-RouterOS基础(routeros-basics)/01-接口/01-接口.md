# 接口

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Interface](https://help.mikrotik.com/docs/spaces/ROS/pages/328207/Interface)

## 目的

分清物理口、PPPoE、网桥、WireGuard。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：打开接口列表

WinBox：`Interfaces`

动作：看到 ether1、pppoe-out1、bridge、wg-demo 等。R=Running。

![第1步](images/01-接口.png)

```routeros
/interface/print
```

## 检查

WinBox：Interfaces

```routeros
/interface/print where running
```

## 常见问题

WAN 口不要再塞进 bridge。
