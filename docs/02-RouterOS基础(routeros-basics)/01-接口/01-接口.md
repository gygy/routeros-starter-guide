# 接口

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Interfaces](https://help.mikrotik.com/docs/spaces/ROS/pages/328071/Interfaces)

## 目的

认出 ether / bridge / pppoe 等接口。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：打开接口表

WinBox：`Interfaces`

看 Name、Type、Running。

![第1步](images/01-接口.png)

```routeros
/interface/print
```

## 检查

WinBox：`Interfaces`

```routeros
/interface/print
```

## 常见问题

口名以你机器为准。
