# IP地址

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[IP Addressing](https://help.mikrotik.com/docs/spaces/ROS/pages/328068/IP+Addressing)

## 目的

给 LAN 桥加上管理地址。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：加地址

WinBox：`IP → Addresses → +`

Address：`192.168.88.1/24`；Interface：`bridge`；OK。

![第1步](images/01-地址.png)

```routeros
/ip/address/add address=192.168.88.1/24 interface=bridge
```

## 检查

WinBox：`IP → Addresses`

```routeros
/ip/address/print
```

## 常见问题

之后 WinBox 可以用这个 IP 连，比 MAC 稳。
