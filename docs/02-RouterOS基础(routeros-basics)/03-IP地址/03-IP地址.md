# IP 地址

> 适用版本：RouterOS 7.x

## 目的

给接口加管理地址。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 先看懂

没有地址，电脑不知道网关在哪。

![图(1) IP地址](images/00-原理.svg)

<p align="center">图(1) IP地址</p>

## 第1步：打开 Addresses

WinBox：`IP → Addresses`

动作：看现有地址。

![图(2) 打开Addresses](images/01-地址.png)

<p align="center">图(2) 打开Addresses</p>


```routeros
/ip/address/print
```

## 第2步：添加 LAN 地址

WinBox：`IP → Addresses → +`

动作：Address=192.168.88.1/24，Interface=bridge。

![图(3) 添加LAN地址](images/02-添加.png)

<p align="center">图(3) 添加LAN地址</p>


```routeros
/ip/address/add address=192.168.88.1/24 interface=bridge
```

## 检查

WinBox：bridge 有 192.168.88.1/24

```routeros
/ip/address/print where interface=bridge
```
