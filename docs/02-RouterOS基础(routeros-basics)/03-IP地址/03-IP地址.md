# IP 地址

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[IP Addressing](https://help.mikrotik.com/docs/spaces/ROS/pages/328068/IP+Addressing)

## 目的

给 bridge 配管理地址 192.168.88.1/24。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：添加 LAN 地址

WinBox：`IP → Addresses → +`

动作：Address=192.168.88.1/24，Interface=bridge，Comment=lab-lan。901 已实配。

![第1步](images/01-地址.png)

```routeros
/ip/address/add address=192.168.88.1/24 interface=bridge comment=lab-lan
```

## 检查

WinBox：Addresses 能看到 192.168.88.1

```routeros
/ip/address/print where interface=bridge
```

## 常见问题
