# 固定IP上网

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[IP Addressing](https://help.mikrotik.com/docs/spaces/ROS/pages/328068/IP+Addressing)

## 目的

运营商给了固定地址、网关。

## 网络

- 示例（请换成合同上的）：WAN `192.0.2.10/30` 网关 `192.0.2.9`
- 接口 `ether1`

## 第1步：WAN 地址

WinBox：`IP → Addresses → +`

填运营商地址和 ether1。

![第1步](images/01-WAN地址.png)

```routeros
/ip/address/add address=192.0.2.10/30 interface=ether1
```

## 第2步：默认路由

WinBox：`IP → Routes → +`

Dst. Address：`0.0.0.0/0`；Gateway：运营商网关。

![第2步](images/02-默认路由.png)

```routeros
/ip/route/add dst-address=0.0.0.0/0 gateway=192.0.2.9
```

## 检查

WinBox：`IP → Routes`

```routeros
/ip/route/print
```

## 常见问题

测试用 `/ping 1.1.1.1`。
