# 1 对 1 NAT

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[NAT](https://help.mikrotik.com/docs/spaces/ROS/pages/8978531/NAT)

## 目的

公网地址映射到内网主机。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：netmap

WinBox：`IP → Firewall → NAT → +`

动作：dstnat netmap 203.0.113.10 -> 192.168.88.10，再配对称 srcnat。

![第1步](images/01-netmap.png)

```routeros
/ip/firewall/nat/add chain=dstnat dst-address=203.0.113.10 action=netmap to-addresses=192.168.88.10
/ip/firewall/nat/add chain=srcnat src-address=192.168.88.10 action=netmap to-addresses=203.0.113.10
```

## 检查

WinBox：双向能通

```routeros
/ip/firewall/nat/print where action=netmap
```

## 常见问题
