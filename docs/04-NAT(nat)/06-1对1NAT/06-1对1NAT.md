# 1对1 NAT

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[NAT](https://help.mikrotik.com/docs/spaces/ROS/pages/3211299/NAT)

## 目的

一个公网地址对应一台内网机（有多余公网时）。

## 网络

- 示例公网 `192.0.2.20` 内网 `192.168.88.20`

## 第1步：srcnat + dstnat

WinBox：`IP → Firewall → NAT`

两条：srcnat 内网出站 to-addresses 公网；dstnat 公网进站 to-addresses 内网。

![第1步](images/01-netmap.png)

```routeros
/ip/firewall/nat/add chain=srcnat src-address=192.168.88.20 action=src-nat to-addresses=192.0.2.20
/ip/firewall/nat/add chain=dstnat dst-address=192.0.2.20 action=dst-nat to-addresses=192.168.88.20
```

## 检查

WinBox：`IP → Firewall → NAT`

```routeros
/ip/firewall/nat/print
```

## 常见问题

没有多余公网就用端口转发。
