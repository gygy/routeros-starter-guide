# 端口放行

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Services](https://help.mikrotik.com/docs/spaces/ROS/pages/328166/Services)

## 目的

只保留需要的管理端口。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：看服务端口

WinBox：`IP → Services`

动作：确认 winbox=8291、ssh=22。

![第1步](images/01-8291.png)

```routeros
/ip/service/print
```

## 检查

WinBox：服务列表正常

```routeros
/ip/service/print
```

## 常见问题

公网不要裸奔 8291。
