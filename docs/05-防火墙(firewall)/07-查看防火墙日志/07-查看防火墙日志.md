# 查看防火墙日志

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Log](https://help.mikrotik.com/docs/spaces/ROS/pages/328080/Log)

## 目的

看规则有没有打到。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：看日志

WinBox：`Log`

Topics 可筛 firewall。临时排错可在规则上 Action 选 log。

![第1步](images/01-日志.png)

```routeros
/log/print where topics~"firewall"
```

## 检查

WinBox：`Log`

```routeros
/log/print
```

## 常见问题

排完把 log 动作关掉，避免刷屏。
