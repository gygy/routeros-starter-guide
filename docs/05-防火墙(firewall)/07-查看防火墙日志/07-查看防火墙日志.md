# 查看防火墙日志

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Logging](https://help.mikrotik.com/docs/spaces/ROS/pages/328151/Logging)

## 目的

需要时给规则加 log，再在 Log 查看。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：打开日志

WinBox：`Log`

动作：筛选相关条目。

![第1步](images/01-日志.png)

```routeros
/log/print
```

## 检查

WinBox：Log 有记录

```routeros
/log/print
```

## 常见问题

长期开 log 会占资源。
