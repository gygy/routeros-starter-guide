# 查看路由表

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Routes](https://help.mikrotik.com/docs/spaces/ROS/pages/59968792/Routes)

## 目的

先会看路由再改路由。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：打开 Routes

WinBox：`IP → Routes`

动作：看 Dst. Address、Gateway、Distance、标志 A/D/C/S。

![第1步](images/01-路由表.png)

```routeros
/ip/route/print
```

## 第2步：找默认路由

WinBox：`IP → Routes`

动作：找到 0.0.0.0/0 且带 A 的条目。

![第2步](images/02-默认.png)

```routeros
/ip/route/print where dst-address=0.0.0.0/0
```

## 检查

WinBox：有 Active 的 0.0.0.0/0

```routeros
/ip/route/print where dst-address=0.0.0.0/0
```

## 常见问题

没有默认路由就上不了网。
