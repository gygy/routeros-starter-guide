# 添加静态路由

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[IP Routing](https://help.mikrotik.com/docs/spaces/ROS/pages/59965516/IP+Routing)

## 目的

去某个网段走指定网关。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：加路由

WinBox：`IP → Routes → +`

Dst. Address：`192.168.1.0/24`；Gateway：`192.168.88.254`；OK。

![第1步](images/01-静态路由.png)

```routeros
/ip/route/add dst-address=192.168.1.0/24 gateway=192.168.88.254
```

## 检查

WinBox：`IP → Routes`

```routeros
/ip/route/print
```

## 常见问题

网关必须能从本机 ARP 到。
