# 添加静态路由

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Routes](https://help.mikrotik.com/docs/spaces/ROS/pages/59968792/Routes)

## 目的

去某网段走指定下一跳。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的）
- 身份示例：`R1`

## 第1步：添加静态路由

WinBox：`IP → Routes → +`

动作：Dst=`198.51.100.0/24`，Gateway=你的下一跳（示例 `192.168.88.254`），Comment=`lab-static`。

![第1步](images/01-静态路由.png)

```routeros
/ip/route/add dst-address=198.51.100.0/24 gateway=192.168.88.254 distance=2 comment=lab-static
```

## 检查

WinBox：路由表出现该网段

```routeros
/ip/route/print where comment=lab-static
```

## 常见问题

网关必须可达。
