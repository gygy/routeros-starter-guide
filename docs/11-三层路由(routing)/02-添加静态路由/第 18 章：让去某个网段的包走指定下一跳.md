# 第 18 章：让去某个网段的包走指定下一跳

> 适用版本：RouterOS 7.x

## 目的

去某网段走指定下一跳。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 网络拓扑及原理图

公司网段不走默认路由时，加一条 S。

![图(1) 静态路由](images/00-原理.png)

<p align="center">图(1) 静态路由</p>

## 第1步：打开 Routes

WinBox：`IP → Routes`

动作：先看现有路由。

![图(2) 打开Routes](images/01-静态路由.png)

<p align="center">图(2) 打开Routes</p>


```routeros
/ip/route/print
```

## 第2步：添加静态

WinBox：`IP → Routes → +`

动作：Dst=198.51.100.0/24，Gateway=下一跳，Comment=lab-static。

![图(3) 添加静态](images/02-添加.png)

<p align="center">图(3) 添加静态</p>


```routeros
/ip/route/add dst-address=198.51.100.0/24 gateway=10.10.88.1 distance=2 comment=lab-static
```

## 第3步：需要时加默认路由

WinBox：`IP → Routes`

动作：上网出口若没有自动的 `0.0.0.0/0`，再加一条 Dst=`0.0.0.0/0`，Gateway=WAN 下一跳或 `pppoe-out1`。

```routeros
/ip/route/print where dst-address=0.0.0.0/0
```

## 检查

WinBox：出现 lab-static；有 Active 的默认路由（若这台机负责上网）

```routeros
/ip/route/print where comment=lab-static
/ip/route/print where dst-address=0.0.0.0/0
```
