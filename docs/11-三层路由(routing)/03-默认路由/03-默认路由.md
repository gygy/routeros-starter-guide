# 默认路由

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[IP Routing](https://help.mikrotik.com/docs/spaces/ROS/pages/59965516/IP+Routing)

## 目的

不知道去哪的包，走这。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：加 0.0.0.0/0

WinBox：`IP → Routes → +`

Dst `0.0.0.0/0`，Gateway 填 WAN 口或对端地址。

![第1步](images/01-默认.png)

```routeros
/ip/route/add dst-address=0.0.0.0/0 gateway=pppoe-out1
```

## 检查

WinBox：`IP → Routes`

```routeros
/ip/route/print where dst-address=0.0.0.0/0
```

## 常见问题

PPPoE 勾选 Add Default Route 时可能已经有了。
