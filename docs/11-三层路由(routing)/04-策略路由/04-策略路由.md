# 策略路由

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[IP Routing](https://help.mikrotik.com/docs/spaces/ROS/pages/59965516/IP+Routing)

## 目的

某类流量走另一张表（v7）。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：加 routing table

WinBox：`Routing → Tables → +`

Name：`to-wan2`。

![第1步](images/01-表.png)

```routeros
/routing/table/add name=to-wan2 fib
```

## 第2步：routing rule

WinBox：`IP → Routes → Rules → +`

Src Address 填要分流的网段，Action Lookup，Table `to-wan2`。

![第2步](images/02-规则.png)

```routeros
/routing/rule/add src-address=192.168.88.0/24 action=lookup table=to-wan2
```

## 检查

WinBox：`Routing → Tables`

```routeros
/routing/rule/print
```

## 常见问题

v7 不要用旧的 routing-mark 当唯一写法。
