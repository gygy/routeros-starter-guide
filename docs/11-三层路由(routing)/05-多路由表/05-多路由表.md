# 多路由表

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[IP Routing](https://help.mikrotik.com/docs/spaces/ROS/pages/59965516/IP+Routing)

## 目的

在指定表里加默认路由。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：表里加默认路由

WinBox：`IP → Routes → +`

Dst `0.0.0.0/0`，Gateway 填第二条线，Routing Table 选 `to-wan2`。

![第1步](images/01-表路由.png)

```routeros
/ip/route/add dst-address=0.0.0.0/0 gateway=192.168.2.1 routing-table=to-wan2
```

## 检查

WinBox：`IP → Routes`

```routeros
/ip/route/print
```

## 常见问题

先有 table 再有 rule。
