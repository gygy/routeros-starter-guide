# 多路由表

> 适用版本：RouterOS 7.x

## 目的

不同表放不同默认路由。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 先看懂

主表管家里，副表管访客或 VPN。

![图(1) 多路由表](images/00-原理.png)

<p align="center">图(1) 多路由表</p>

## 第1步：打开 Routes

WinBox：`IP → Routes`

动作：确认能选 Routing Table。

![图(2) 打开Routes](images/01-表路由.png)

<p align="center">图(2) 打开Routes</p>


```routeros
/ip/route/print
```

## 第2步：表内加默认路由

WinBox：`IP → Routes → +`

动作：Routing Table=via-wan2，Dst=0.0.0.0/0，Gateway=备线。

![图(3) 表内加默认路由](images/02-添加.png)

<p align="center">图(3) 表内加默认路由</p>


```routeros
/ip/route/add routing-table=via-wan2 dst-address=0.0.0.0/0 gateway=ether2
```

## 检查

WinBox：对应表有默认路由

```routeros
/ip/route/print where routing-table=via-wan2
```
