# 抓包

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Packet Sniffer](https://help.mikrotik.com/docs/spaces/ROS/pages/328190/Packet+Sniffer)

## 目的

保存 cap 用 Wireshark 看。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：Packet Sniffer

WinBox：`Tools → Packet Sniffer`

Interface 选口，File Name `flash/cap1`，Start 再 Stop，Files 里下载。

![第1步](images/01-sniffer.png)

```routeros
/tool/sniffer/set file-name=flash/cap1.pcap
/tool/sniffer/start
/tool/sniffer/stop
```

## 检查

WinBox：`Files`

```routeros
/file/print
```

## 常见问题

不要在生产口长时间抓包。
