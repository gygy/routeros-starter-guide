# 抓包

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Packet Sniffer](https://help.mikrotik.com/docs/spaces/ROS/pages/24952854/Tools)

## 目的

抓包分析。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：打开 Sniffer

WinBox：`Tools → Packet Sniffer`

动作：Interface 选对的口，Start。

![第1步](images/01-sniffer.png)

```routeros
/tool/sniffer/quick interface=bridge
```

## 第2步：看 Files

WinBox：`Files`

动作：抓包文件可导出分析。

![第2步](images/02-cli.png)

```routeros
/file/print
```

## 检查

WinBox：有抓包输出或文件

```routeros
/tool/sniffer/quick interface=bridge
```
