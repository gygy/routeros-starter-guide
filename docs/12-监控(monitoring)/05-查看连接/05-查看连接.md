# 查看连接

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Connection Tracking](https://help.mikrotik.com/docs/spaces/ROS/pages/328021/Connection+Tracking)

## 目的

看 NAT/防火墙跟踪到的会话。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：Connections

WinBox：`IP → Firewall → Connections`

看 Src/Dst。

![第1步](images/01-conn.png)

```routeros
/ip/firewall/connection/print
```

## 检查

WinBox：`IP → Firewall → Connections`

```routeros
/ip/firewall/connection/print
```

## 常见问题

太多连接时查是否中病毒或 BT。
