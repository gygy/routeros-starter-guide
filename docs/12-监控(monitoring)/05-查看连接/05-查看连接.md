# 查看连接

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Connections](https://help.mikrotik.com/docs/spaces/ROS/pages/328122/Filter)

## 目的

看当前连接跟踪。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的）
- 身份示例：`R1`

## 第1步：Connections

WinBox：`IP → Firewall → Connections`

动作：可按地址过滤。

![第1步](images/01-conn.png)

```routeros
/ip/firewall/connection/print
```

## 检查

WinBox：有连接条目

```routeros
/ip/firewall/connection/print count-only
```

## 常见问题

连接过多会吃内存。
