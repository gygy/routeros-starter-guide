# 查看日志

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Logging](https://help.mikrotik.com/docs/spaces/ROS/pages/328151/Logging)

## 目的

系统事件都在 Log。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的）
- 身份示例：`R1`

## 第1步：打开 Log

WinBox：`Log`

动作：按时间倒序看 critical/error。

![第1步](images/01-log.png)

```routeros
/log/print
```

## 检查

WinBox：能看到近期日志

```routeros
/log/print
```

## 常见问题

登录失败也在这里。
