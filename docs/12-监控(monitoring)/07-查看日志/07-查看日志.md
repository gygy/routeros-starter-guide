# 查看日志

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Log](https://help.mikrotik.com/docs/spaces/ROS/pages/328080/Log)

## 目的

看掉线、拨号、登录。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：Log

WinBox：`Log`

往下翻最近事件。

![第1步](images/01-log.png)

```routeros
/log/print
```

## 检查

WinBox：`Log`

```routeros
/log/print
```

## 常见问题

登录失败很多要收紧 WinBox。
