# 远程管理

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[WireGuard](https://help.mikrotik.com/docs/spaces/ROS/pages/69664792/WireGuard)

## 目的

远程优先走 VPN，再开管理。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：确认 VPN

WinBox：`WireGuard`

动作：远程先连 wg，再访问管理地址。

![第1步](images/01-远程.png)

```routeros
/interface/wireguard/print
```

## 第2步：限制管理源

WinBox：`IP → Services`

动作：WinBox/SSH Available From 含 VPN 网段。

![第2步](images/02-服务.png)

```routeros
/ip/service/print
```

## 检查

WinBox：经 VPN 能管理，公网不裸开

```routeros
/interface/wireguard/print
/ip/service/print
```

## 常见问题

不要把 8291 对 0.0.0.0/0 裸开。
