# 远程管理

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Services](https://help.mikrotik.com/docs/spaces/ROS/pages/328166/Services)

## 目的

远程只走 VPN，不裸奔管理口。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的）
- 身份示例：`R1`

## 第1步：收紧服务

WinBox：`IP → Services`

动作：关掉 www/ftp/telnet；WinBox/SSH 仅 VPN 或 LAN。901 已关 www/ftp/telnet。

![第1步](images/01-远程.png)

```routeros
/ip/service/set www disabled=yes
/ip/service/set ftp disabled=yes
/ip/service/set telnet disabled=yes
```

## 检查

WinBox：外网扫不到管理口

```routeros
/ip/service/print
```

## 常见问题

先 VPN 再管理。
