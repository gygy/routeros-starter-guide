# 网络故障排查流程

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Ping](https://help.mikrotik.com/docs/spaces/ROS/pages/328187/Ping)

## 目的

线 → 地址 → 路由 → NAT → DNS。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：按层 ping

WinBox：`Tools → Ping`

先 `192.168.88.1`，再 `1.1.1.1`，再 ping 域名。

![第1步](images/01-流程.png)

```routeros
/ping 192.168.88.1 count=3
/ping 1.1.1.1 count=3
/ping www.example.com count=3
```

## 检查

WinBox：`IP → Routes`

```routeros
/ip/route/print
```

## 常见问题

通 IP 不通域名就是 DNS。
