# 网络故障排查流程

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Ping](https://help.mikrotik.com/docs/spaces/ROS/pages/328151/Ping)

## 目的

按顺序：接口 → 地址 → 路由 → NAT → DNS → 防火墙。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的）
- 身份示例：`R1`

## 第1步：按序检查

WinBox：`Interfaces / Addresses / Routes / NAT / DNS`

动作：901 演示环境可对照 Resources 与接口状态。

![第1步](images/01-流程.png)

```routeros
/interface/print
/ip/address/print
/ip/route/print
/ip/firewall/nat/print
/ip/dns/print
```

## 检查

WinBox：定位到第一处异常

```routeros
/ping 1.1.1.1 count=3
```
