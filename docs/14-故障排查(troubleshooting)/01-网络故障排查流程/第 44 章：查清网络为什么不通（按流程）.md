# 第 44 章：查清网络为什么不通（按流程）

> 适用版本：RouterOS 7.x

## 目的

按层排查：口→地址→路由→DNS→防火墙。

## 网络

- 示例 LAN：`192.168.88.0/24`，网关 `192.168.88.1`，接口 `bridge`（改成你的口）
- WAN 示例：`pppoe-out1` 或 `ether1`
- 密码示例：`********`（填你自己的管理员密码）
- 身份示例：`R1`

## 第1步：看接口

WinBox：`Interfaces`

动作：WAN/LAN 是否 Running。

![图(1) 看接口](images/01-流程.png)

<p align="center">图(1) 看接口</p>


```routeros
/interface/print
```

## 第2步：看路由与 DNS

WinBox：`IP → Routes / DNS`

动作：有默认路由；DNS 可解析。

![图(2) 看路由与DNS](images/02-路由.png)

<p align="center">图(2) 看路由与DNS</p>


```routeros
/ip/route/print where dst-address=0.0.0.0/0
/ping 1.1.1.1 count=2
```

## 第3步：Ping 和 Torch

WinBox：`Tools → Ping`：先 ping `192.168.88.1`，再 ping `1.1.1.1`。  
`Tools → Torch`：选 WAN 口，看有没有流量。不通时再看 `Log` 和 `IP → Firewall → Connections`。

```routeros
/ping 192.168.88.1 count=4
/ping 1.1.1.1 count=4
/log/print
```

## 检查

WinBox：定位到断层的一层（口、地址、路由、DNS 或防火墙）

```routeros
/interface/print
/ip/route/print
/ping 1.1.1.1 count=2
```
