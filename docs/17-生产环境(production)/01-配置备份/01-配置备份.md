# 配置备份

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Backup](https://help.mikrotik.com/docs/spaces/ROS/pages/40960324/Backup)

## 目的

定期 `/system/backup/save`。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：Backup

WinBox：`Files → Backup`

生成 `.backup`，下载到电脑。

![第1步](images/01-bak.png)

```routeros
/system/backup/save name=r1
```

## 检查

WinBox：`Files`

```routeros
/file/print
```
