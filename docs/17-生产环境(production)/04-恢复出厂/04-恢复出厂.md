# 恢复出厂

> 适用版本：RouterOS 7.x  
> 管理工具：WinBox  
> 官方依据：[Reset](https://help.mikrotik.com/docs/spaces/ROS/pages/40959838/Reset+Button)

## 目的

清空配置。会断网。

## 网络

- 示例 LAN：`192.168.88.1/24`，接口 `bridge`（改成你的口）
- WAN 示例口：`ether1`
- 密码示例：`********`（填你自己的）

## 第1步：Reset

WinBox：`New Terminal`

仅当你确定。可保留用户：按文档参数。

![第1步](images/01-reset.png)

```routeros
/system/reset-configuration no-defaults=no skip-backup=no
```

## 检查

WinBox：`New Terminal`

```routeros
/system/identity/print
```

## 常见问题

先备份。MAC 连接还能再进去。
